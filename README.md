# Traffic_Light_Controller_Verilog-
A digital logic project that controls traffic signal sequencing using Verilog HDL and finite state machine concepts.


## Introduction

This project implements a Traffic Light Controller using Verilog HDL. The design controls the sequence of traffic signals by changing between different states such as Red, Yellow, and Green. The project was developed and simulated in AMD Vivado as part of digital design and Verilog HDL learning.

## Project Objectives

- Understand the basics of Finite State Machine (FSM) design.
- Implement a Traffic Light Controller in Verilog HDL.
- Verify the functionality using a testbench.
- Analyze the simulation and synthesis results in Vivado.

## Software Used

- AMD Vivado ML Edition
- Verilog HDL

## Files Included

- `traffic_light_controller.v` – Main design module
- `traffic_light_tb.v` – Testbench for simulation
- `waveForm.png` – Simulation waveform output
- `synthesis.png` – Synthesis result

## Working

The controller changes traffic signals in a predefined sequence. Each state represents a particular traffic light condition, and transitions occur according to the logic defined in the Verilog code.

The design was verified through simulation, and the expected output was observed in the waveform results.

## Results

- Successfully designed and simulated the Traffic Light Controller.
- Verified correct state transitions through the testbench.
- Completed synthesis in AMD Vivado without errors.
